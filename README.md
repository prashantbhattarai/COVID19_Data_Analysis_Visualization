# COVID-19 Data Analysis & Visualization

## 📌 Overview
This project analyzes and visualizes COVID-19 data over time.  
It covers confirmed cases, deaths, and recovered cases using Python's **pandas** and **matplotlib** libraries.

## 🛠 Tech Stack
Python | pandas | matplotlib | tabulate

## 🚀 Features
- Cleans messy CSV data (handles missing values and converts dates)
- Displays data neatly in a tabular format
- Visualizes:
  - Confirmed cases over time (line plot)
  - Deaths over time (bar chart)
  - Recovered cases over time (line plot)
  - Overall Confirmed/Deaths/Recovered ratio (pie chart)
